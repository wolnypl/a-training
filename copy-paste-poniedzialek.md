## Lab 1 — Instalacja Dockera

Polecenia wykonuj jako root, w podanej kolejności.

```bash
yum config-manager --add-repo=http://download.docker.com/linux/centos/docker-ce.repo
```

```bash
yum repolist
```

```bash
yum search docker
```

```bash
yum info docker-ce
```

```bash
yum install -y docker-ce
```
